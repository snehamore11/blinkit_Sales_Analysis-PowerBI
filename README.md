# blinkit_Sales_Analysis-PowerBI
Blinkit Sales Analysis Dashboard created using Microsoft Power BI to anaylze sales performance and business insights

## Dashboard Preview
![Blinkit Sales Dashboard](dashboard.png)

## Project Overview

The Blinkit Sales Analysis project focuses on analyzing sales performance and understanding business insights using Power BI.

The dashboard provides insights into total sales, average sales, number of items, customer ratings, outlet locations, and outlet types.

The main objective of this project is to identify sales trends and help businesses make better data-driven decisions.

## Tools & Technologies Used

- Power BI: For creating interactive dashboards and data visualization.
- Microsoft Excel: For data preparation and basic data cleaning.
- Data Analysis: For analyzing sales performance and identifying business insights.

## Key Insights

- Total Sales: $1.20 Million
- Average Sales: $141
- Total Number of Items: 8,523
- Average Customer Rating: 3.9
- Analyzed sales performance across different outlet locations.
- Compared sales across different outlet types and item categories.
- Identified sales trends based on outlet establishment year.

 ## Dashboard Features

- Interactive sales dashboard.
- Total Sales and Average Sales KPIs.
- Outlet Location Type and Outlet Size filters.
- Sales analysis by Item Type.
- Fat Content analysis.
- Outlet Establishment Year analysis.
- Outlet Location and Outlet Type comparison.
- Average Customer Rating analysis.
